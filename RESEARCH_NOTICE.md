# Research Notice

The performance evidence in this repository is simulated. It is not live
trading performance, investment advice, an offer, or a forecast of future
returns.

The public Python package is an executable architecture example built on
synthetic inputs. It demonstrates timing, lifecycle, portfolio, execution,
accounting, and audit controls. It does not contain the private relationship
model, empirical thresholds, raw market data, or the implementation that
generated the reported performance evidence.

Historical market archives are not distributed by this repository. Aggregate
figures are retained only to document the frozen research result and its
limitations.
